## Quick start

```bash
# 1. Clone and install
git clone https://github.com/brunklab/ecdna-bench.git
cd ecdna-bench
conda env create -f env/environment.yml
conda activate ecdna-bench
pip install -e .

# 2. Point to your data
cp configs/paths.example.yaml configs/paths.local.yaml
# edit configs/paths.local.yaml to set rgb_dir, gt_mask_dir, etc.

# 3. Verify installation
pytest -q                                  # 112 tests, ~4 s

# 4. Reproduce results from the frozen CSVs
make benchmark                             # re-evaluates all six models
# Figures are regenerated by running notebooks/01..05 (see below).
```

## Evaluation framework

Every model output is reduced to a canonical **binary mask** at original
resolution, then evaluated through a shared three-step pipeline:

1. **Connected-component extraction** — 8-connectivity, minimum area 3 px.
2. **Hungarian matching** — cost function
   `C_ij = α(1 − IoU_ij) + (1 − α) · d_ij / d_max`,
   with default parameters `d_max = 20 px`, `IoU_min = 0.1`, `α = 0.5`.
3. **Policy** — **OR** (match valid if distance ≤ d_max *or* IoU ≥ IoU_min)
   or **AND** (both conditions required).

**Outcome categories** — every prediction lands in exactly one bucket:

| Bucket | Meaning |
|--------|---------|
| TP | Prediction assigned to a GT object |
| FP | Prediction with no valid GT candidate |
| FN | GT object with no matched prediction |
| **Ignored** | Prediction had a valid GT candidate but lost the assignment |

**Metric families:** object (precision / recall / F1), pixel (Dice / IoU),
count (MAE / RMSE / bias / Pearson r / Spearman ρ / MdAPE).

Headline results use the **OR** policy, `d_max = 20 px`, `IoU_min = 0.1`,
and report **pooled (micro-averaged)** F1 over all matched objects.

## ecCount

A compact U-Net trained to predict **soft Gaussian heatmaps** centred on
ecDNA loci, then post-processed to extract point predictions.

| Property | Value |
|----------|-------|
| Input size | 1024 × 1224 px |
| Target σ | 1.0 px |
| Architecture | U-Net, base = 32, GroupNorm(8), bilinear upsample |
| Parameters | 7,849,601 trainable |
| Loss | wBCE (pos_weight = 20) + SoftDice |
| Optimiser | Adam lr = 1e-4, batch = 2, 70 epochs |
| Scheduler | ReduceLROnPlateau (patience = 5, factor = 0.5) |
| Best checkpoint | epoch 49, val loss 0.6421 |
| Post-processing | smooth(σ = 0.5) → ROI re-apply → peaks(thr = 0.35) → NMS(2 px) |

Source: `release/model_checkpoints/` (shipped via the BioImage Archive),
`train_history.csv`.

## Reproducing the paper figures

All figures are generated by the five notebooks, which read only from the
frozen CSVs in `release/frozen_results/` and write to
`release/figures/notebookNN/`:

```
notebooks/01_dataset_exploration.ipynb       → Figure 1 (dataset composition)
notebooks/02_classical_pipeline.ipynb        → Figure 3 (classical pipeline + BO)
notebooks/03_models_comparison.ipynb         → Figure 4 (qualitative gallery)
notebooks/04_matching_and_sensitivity.ipynb  → Figure 2, Supp. (matching, sensitivity)
notebooks/05_finalisation.ipynb              → Figure 5, 6 (ecCount + benchmark)
```

See [`docs/REPRODUCTION.md`](docs/REPRODUCTION.md) for the complete
figure → notebook → output-file mapping.

## Running the full pipeline from scratch

```bash
# Build metadata + QC
python -m ecdna_bench.cli.build_metadata --config configs/default.yaml
python -m ecdna_bench.cli.run_qc         --config configs/default.yaml

# Optimise and run the classical pipeline
python -m ecdna_bench.cli.optimize_classical --stage all --config configs/default.yaml
python -m ecdna_bench.cli.run_classical      --config configs/default.yaml

# Train and run ecCount
python -m ecdna_bench.cli.train_eccount --config configs/default.yaml
python -m ecdna_bench.cli.run_eccount   --config configs/default.yaml

# Harmonise external baselines
python -m ecdna_bench.cli.run_baseline --model ecseg        --config configs/default.yaml
python -m ecdna_bench.cli.run_baseline --model mia          --config configs/default.yaml
python -m ecdna_bench.cli.run_baseline --model label_engine --config configs/default.yaml

# Benchmark + sensitivity
python -m ecdna_bench.cli.benchmark   --config configs/default.yaml
python -m ecdna_bench.cli.sensitivity --config configs/default.yaml

# Figures: run notebooks/01..05
```

Or use the Makefile shortcuts: `make benchmark`, `make sensitivity`
(run `make help` for the full list).
